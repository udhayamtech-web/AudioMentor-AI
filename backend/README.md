# AudioMentor AI

Turn Every Voice into Knowledge.

AudioMentor AI is a multilingual voice-to-text
and AI summarization application.

## Features
- Audio to Text Transcription
- Tamil, English and Tanglish Support
- AI-Powered Summarization
- Multiple Summary Languages

## Technologies Used
- Python
- Streamlit
- FastAPI
- Hugging Face
- Groq API
- Google Colab

## Project Structure
- frontend: Streamlit application
- backend: FastAPI and transcription notebook
